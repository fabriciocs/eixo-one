# Protocolo Git

1. Executar `git status` antes de qualquer alteracao.
2. Identificar a branch atual.
3. Nao sobrescrever alteracoes existentes do usuario.
4. Criar branch `feature/<slug-da-task>` quando aplicavel.
5. Antes do commit, revisar `git status` e `git diff`.
6. Adicionar somente arquivos da task.
7. Commit sugerido: `feat: <resumo da task>`.
8. Push sugerido: `git push -u origin feature/<slug-da-task>`.
9. Se commit ou push falhar, registrar motivo, erro e comandos para execucao manual.
