# Checklist de QA

- Requisitos criticos mapeados para testes.
- Casos positivos, negativos e de borda definidos.
- Testes de permissao e autorizacao incluidos.
- Testes de API ou contrato quando houver backend.
- Testes de componente, fluxo ou E2E quando houver frontend.
- Acessibilidade considerada.
- Seguranca basica validada.
- Lint, typecheck, testes e build executados quando disponiveis.
- Evidencias registradas em `11_evidencias_de_validacao.md`.
