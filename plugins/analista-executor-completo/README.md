# Plugin Codex - Analista Executor Completo

Plugin local para Codex com a skill `analista-executor-completo`.

## Estrutura criada

Este scaffold usa o formato repo-local recomendado:

- `.agents/plugins/marketplace.json`
- `plugins/analista-executor-completo/`

## Como instalar no Codex

Abra o Codex na raiz deste repositorio e execute:

```bash
/plugins
```

Depois selecione o marketplace local `Plugins Locais` e instale `analista-executor-completo`.

## Uso

```text
@analista-executor-completo Execute esta funcionalidade ponta a ponta conforme o processo obrigatorio.
```
