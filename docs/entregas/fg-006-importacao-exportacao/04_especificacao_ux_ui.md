# FG-006 - Especificacao UX/UI

## Pagina entregue

- Uma tela administrativa unica com duas areas: historico de jobs e workspace de criacao/detalhe.

## Elementos principais

- Filtros por busca, tipo e status.
- Formulario de novo job com entidade, formato, modo, nome de arquivo e conteudo tabular.
- Acoes separadas para criar importacao, criar exportacao e executar job selecionado.
- Detalhe com status, erros, preview e saida gerada.

## Estados cobertos

- loading
- empty state
- erro recuperavel
- sem permissao
- sucesso com snackbar
